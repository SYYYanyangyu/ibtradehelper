## 〇、先复习一下这套架构的"套路"（太久没写必看）

本项目的四层是**单向依赖**，内层不知道外层的存在：

```
Api ──▶ Infrastructure ──▶ Application ──▶ Domain
```

每一层只认**自己这一层 + 更里面的层**。所以写新功能时，永远**从最里面往外写**：

| 步骤 | 你在哪层写 | 写什么 | 关键规则 |
|------|-----------|--------|---------|
| 1 | `Domain` | 实体类 + 枚举 + 仓储**接口** | 零外部依赖，不引用 EF / Http |
| 2 | `Application` | DTO + 用例 Service（接口+实现） | 只依赖 Domain，不知道数据库细节 |
| 3 | `Infrastructure` | EF 配置 + 仓储**实现** + 外部客户端 | 实现 Domain 里的接口 |
| 4 | `Api` | Controller | 只调用 Application 的 Service |

**C#/.NET 8 的几个新语法（你可能忘了）**，本骨架全在用：

- **file-scoped namespace**：`namespace IBTrade.Domain.Entities;` 一行搞定，不用写大括号包住整个文件。
- **primary constructor（主构造函数）**：`public class Foo(IFoo dep) : IFoo { }` —— 括号里的参数自动变成私有字段，直接用在方法里。
- **record**：`public record PositionDto(...) { }` —— 不可变 DTO，自动生成构造器和相等比较，适合对外传输数据。
- **required**：`public required string Symbol { get; set; }` —— 构造时强制赋值，否则编译报错。
- **箭头函数方法**：`public decimal MarketValue => Quantity * MarketPrice;` —— 计算属性，不存库。

**每次加完东西，验证三条命令**（在 `trade/` 目录下执行）：
```bash
dotnet build                                   # 编译，必须 0 警告 0 错误
dotnet run --project src/IBTrade.Api           # 启动，访问 http://localhost:8090/swagger
# 或只看编译：dotnet build IBTrack.sln
```

namespace IBTrade.Domain.Entities;

/// <summary>成交：某一笔已发生的买卖记录。</summary>
public class Trade : Entity
{
    public required string AccountId { get; set; }
    public required string Symbol { get; set; }
    public AssetType AssetType { get; set; }
    public Side Side { get; set; }
    public string Currency { get; set; } = "USD";

    /// <summary>成交数量（正数）</summary>
    public decimal Quantity { get; set; }

    /// <summary>成交单价</summary>
    public decimal Price { get; set; }

    /// <summary>佣金/手续费</summary>
    public decimal Commission { get; set; }

    /// <summary>成交时间（UTC）</summary>
    public DateTime TradeTimeUtc { get; set; }

    /// <summary>成交额（不含费）= 数量 × 价格</summary>
    public decimal GrossAmount => Quantity * Price;

    /// <summary>净发生额 = 买加费 / 卖减费</summary>
    public decimal NetAmount => Side == Side.Buy
        ? -(GrossAmount + Commission)
        : (GrossAmount - Commission);
}

### 3.2 在 `Infrastructure` 写 Flex 客户端（HTTP 下载 + XML 解析）
新建：`src/IBTrade.Infrastructure/IBKR/FlexQueryClient.cs`
```csharp
using System.Xml.Linq;
using IBTrade.Application.Ingestion.Dtos;
using IBTrade.Domain.Enums;

namespace IBTrade.Infrastructure.IBKR;

/// <summary>调用 IBKR Flex Web Service 下载报表 XML 并解析。</summary>
public class FlexQueryClient(HttpClient httpClient)
{
    private const string BaseUrl = "https://gdcdyn.interactivebrokers.com/routergf/php/api.php";

    public async Task<string> DownloadXmlAsync(string token, string queryId, CancellationToken ct = default)
    {
        var url = $"{BaseUrl}?t=fcx&q={Uri.EscapeDataString(queryId)}&v=3&token={Uri.EscapeDataString(token)}";
        using var resp = await httpClient.GetAsync(url, ct);
        resp.EnsureSuccessStatusCode();
        return await resp.Content.ReadAsStringAsync(ct);
    }

    public FlexSnapshot Parse(string xml)
    {
        var doc = XDocument.Parse(xml);
        var stmt = doc.Descendants("FlexStatement").First();

        var acct = stmt.Element("AccountInformation")!;
        var account = new FlexAccountDto(
            acct.Element("accountId")!.Value,
            acct.Element("baseCurrency")?.Value ?? "USD",
            acct.Element("alias")?.Value);

        var positions = stmt.Elements("OpenPositions").Elements("OpenPosition").Select(e => new FlexPositionDto(
            e.Element("accountId")!.Value,
            e.Element("symbol")!.Value,
            Enum.Parse<AssetType>(e.Element("assetType")!.Value, ignoreCase: true),
            e.Element("currency")?.Value ?? "USD",
            decimal.Parse(e.Element("position")!.Value),
            decimal.Parse(e.Element("avgPrice")!.Value),
            decimal.Parse(e.Element("marketPrice")!.Value))).ToList();

        var trades = stmt.Elements("Trades").Elements("Trade").Select(e => new FlexTradeDto(
            e.Element("accountId")!.Value,
            e.Element("symbol")!.Value,
            Enum.Parse<AssetType>(e.Element("assetType")!.Value, ignoreCase: true),
            e.Element("side")!.Value.Equals("SELL", StringComparison.OrdinalIgnoreCase) ? Side.Sell : Side.Buy,
            e.Element("currency")?.Value ?? "USD",
            decimal.Parse(e.Element("quantity")!.Value),
            decimal.Parse(e.Element("price")!.Value),
            decimal.Parse(e.Element("commission")?.Value ?? "0"),
            DateTime.Parse(e.Element("dateTime")!.Value, null, System.Globalization.DateTimeStyles.AssumeUniversal).ToUniversalTime())).ToList();

        return new FlexSnapshot(account, positions, trades);
    }
}
```

> ⚠️ Flex 报表的 XML 元素名（如 `OpenPosition`、`avgPrice`）以你实际导出的报表为准。第一次跑先 `DownloadXmlAsync` 把 XML 存盘看一眼字段名，再对齐上面的 `Element(...)` 名字。这是 IBKR 接入里最容易出错的一步。

### 3.3 在 `Application` 实现入库用例
新建：`src/IBTrade.Application/Ingestion/IngestionService.cs`
```csharp
using IBTrade.Application.Ingestion.Dtos;
using IBTrade.Domain.Entities;
using IBTrade.Domain.Repositories;

namespace IBTrade.Application.Ingestion;

public class IngestionService(
    FlexQueryClient flexClient,
    IAccountRepository accountRepo,
    IPositionRepository positionRepo,
    ITradeRepository tradeRepo) : IIngestionService
{
    public async Task IngestAsync(string queryId, CancellationToken ct = default)
    {
        var token = Environment.GetEnvironmentVariable("IBKR_FLEX_TOKEN")
                    ?? throw new InvalidOperationException("缺少环境变量 IBKR_FLEX_TOKEN");

        var xml = await flexClient.DownloadXmlAsync(token, queryId, ct);
        var snap = flexClient.Parse(xml);

        // 账户（upsert：有则留，无则加）
        var existing = await accountRepo.GetByAccountIdAsync(snap.Account.AccountId, ct);
        if (existing is null)
        {
            await accountRepo.AddAsync(new Account
            {
                AccountId = snap.Account.AccountId,
                BaseCurrency = snap.Account.BaseCurrency,
                Alias = snap.Account.Alias
            }, ct);
            await accountRepo.SaveChangesAsync(ct);
        }

        // 持仓：先清后写（快照型数据，最简单可靠）
        // 简化做法：直接 Add，生产环境建议先按 AccountId 删旧再插新，或用 upsert。
        foreach (var p in snap.Positions)
            await positionRepo.AddAsync(new Position
            {
                AccountId = p.AccountId,
                Symbol = p.Symbol,
                AssetType = p.AssetType,
                Currency = p.Currency,
                Quantity = p.Quantity,
                AvgCost = p.AvgCost,
                MarketPrice = p.MarketPrice
            }, ct);

        // 成交：本批增量写入
        await tradeRepo.AddRangeAsync(snap.Trades.Select(t => new Trade
        {
            AccountId = t.AccountId,
            Symbol = t.Symbol,
            AssetType = t.AssetType,
            Side = t.Side,
            Currency = t.Currency,
            Quantity = t.Quantity,
            Price = t.Price,
            Commission = t.Commission,
            TradeTimeUtc = t.TradeTimeUtc
        }), ct);

        await positionRepo.SaveChangesAsync(ct);
        await tradeRepo.SaveChangesAsync(ct);
    }
}
```

## 阶段四：盈亏计算与看板 API

> 目标：在已有 `Position` 未实现盈亏基础上，加一个"组合汇总"用例：总市值、总未实现盈亏、已实现盈亏（来自 Trade 历史）、按标的拆分明细。
> 未实现盈亏直接取自 `Position` 快照（IBKR 已算好平均成本与市场价）；已实现盈亏按成交历史用 **FIFO** 配对算出。

### 4.1 DTO（都在 `Application`）

using IBTrade.Domain.Entities;

namespace IBTrade.Application.Portfolio.Dtos;

/// <summary>单标的盈亏明细：合并未实现（持仓快照）与已实现（成交历史 FIFO）。</summary>
public record PositionPnlDto(
    long Id,
    string AccountId,
    string Symbol,
    string AssetType,
    string Currency,
    decimal Quantity,
    decimal AvgCost,
    decimal MarketPrice,
    decimal MarketValue,
    decimal UnrealizedPnl,
    decimal RealizedPnl,
    decimal CostBasis)     // 当前持仓成本 = 平均成本 × 数量
{
    public static PositionPnlDto FromEntity(Position p, decimal realizedPnl) => new(
        p.Id, p.AccountId, p.Symbol, p.AssetType.ToString(), p.Currency,
        p.Quantity, p.AvgCost, p.MarketPrice, p.MarketValue, p.UnrealizedPnl,
        realizedPnl, p.AvgCost * p.Quantity);
}

### 4.2 用例 Service（Application）
新建：`src/IBTrade.Application/Portfolio/IPortfolioService.cs` + `PortfolioService.cs`
```csharp
using System.Collections.Generic;
using System.Linq;
using IBTrade.Application.Portfolio.Dtos;
using IBTrade.Domain.Entities;
using IBTrade.Domain.Enums;
using IBTrade.Domain.Repositories;

namespace IBTrade.Application.Portfolio;

public interface IPortfolioService
{
    Task<PortfolioSummaryDto> GetSummaryAsync(string? accountId, CancellationToken ct = default);
}

public class PortfolioService(IPositionRepository positionRepository, ITradeRepository tradeRepository)
    : IPortfolioService
{
    public async Task<PortfolioSummaryDto> GetSummaryAsync(string? accountId, CancellationToken ct = default)
    {
        var positions = string.IsNullOrWhiteSpace(accountId)
            ? await positionRepository.GetAllAsync(ct)
            : await positionRepository.GetByAccountAsync(accountId, ct);

        var trades = string.IsNullOrWhiteSpace(accountId)
            ? await tradeRepository.GetAllAsync(ct)
            : await tradeRepository.GetByAccountAsync(accountId, ct);

        var realizedByKey = ComputeRealizedPnl(trades);   // 按 (账户, 标的) FIFO 配对

        var positionDtos = positions.Select(p =>
        {
            var key = (p.AccountId, p.Symbol);
            var realized = realizedByKey.TryGetValue(key, out var r) ? r : 0m;
            return PositionPnlDto.FromEntity(p, realized);
        }).ToList();

        return new PortfolioSummaryDto(
            AccountId: string.IsNullOrWhiteSpace(accountId) ? "ALL" : accountId!,
            TotalMarketValue: positionDtos.Sum(x => x.MarketValue),
            TotalUnrealizedPnl: positionDtos.Sum(x => x.UnrealizedPnl),
            TotalRealizedPnl: positionDtos.Sum(x => x.RealizedPnl),
            TotalCostBasis: positionDtos.Sum(x => x.CostBasis),
            TotalPnl: positionDtos.Sum(x => x.UnrealizedPnl + x.RealizedPnl),
            PositionCount: positionDtos.Count,
            AsOfUtc: DateTime.UtcNow,
            Positions: positionDtos);
    }

    /// <summary>FIFO 已实现盈亏：买入入队成批次（佣金资本化进成本），卖出按时间匹配最早批次。</summary>
    private static Dictionary<(string AccountId, string Symbol), decimal> ComputeRealizedPnl(
        IReadOnlyList<Trade> trades)
    {
        var result = new Dictionary<(string, string), decimal>();
        foreach (var group in trades.GroupBy(t => (t.AccountId, t.Symbol)))
        {
            // 每个批次：(剩余数量, 买入单价, 剩余未摊佣金)
            var lots = new Queue<(decimal Qty, decimal Price, decimal RemainingCommission)>();
            decimal realized = 0m;
            foreach (var t in group.OrderBy(x => x.TradeTimeUtc))
            {
                if (t.Side == Side.Buy) { lots.Enqueue((t.Quantity, t.Price, t.Commission)); continue; }

                var sellQty = t.Quantity;
                var proceeds = t.Quantity * t.Price - t.Commission;   // 卖出收入（扣佣金）
                decimal costBasis = 0m;
                while (sellQty > 0 && lots.Count > 0)
                {
                    var lot = lots.Dequeue();
                    var matched = Math.Min(sellQty, lot.Qty);
                    var commissionShare = lot.RemainingCommission * (matched / lot.Qty);
                    costBasis += matched * lot.Price + commissionShare;
                    sellQty -= matched;
                    var remainingQty = lot.Qty - matched;
                    if (remainingQty > 0)
                        lots.Enqueue((remainingQty, lot.Price, lot.RemainingCommission - commissionShare));
                }
                realized += proceeds - costBasis;
            }
            result[group.Key] = realized;
        }
        return result;
    }
}
```
> 已实现盈亏用 **FIFO（先进先出）** 配对：每笔买入当成一个"成本批次"（买入佣金按比例资本化进成本），卖出按时间顺序匹配最早批次，差额即已实现盈亏。比简单用 `NetAmount` 累计更贴近券商口径，卖空/加仓也成立。

## 阶段五：接回 KnowHub（让 Agent 能问持仓）

> 目标：给 KnowHub 的 Agent 暴露持仓/组合数据。两条路，推荐先做 **REST（最简单）**，后续再上 MCP。

### 5.1 最快路径：REST 直连（KnowHub 后端已有 HTTP 客户端）
你现在的 API 已经够用：`GET /api/positions`、`GET /api/portfolio/summary`。KnowHub 后端用 `httpx` 调 `http://host.docker.internal:8090/api/portfolio/summary?accountId=xxx` 即可。
- 在 docker 网络里，IBTrade 需加入同一个 compose 网络，端口暴露 `8090`。
- CORS 已在 `Program.cs` 放开（`AllowAnyOrigin`），跨容器调用无碍。

### 5.2 进阶路径：MCP Server（让 Agent 像调工具一样调）
若要做标准 MCP，可加一个轻量 MCP 层（用 `ModelContextProtocol` 官方包），把 `IPortfolioService` / `IPositionService` 包成 tools：`get_positions`、`get_portfolio_summary`。
- 这是一个独立小项目或放在 `Api` 里用 `AddMcpServer` 暴露 SSE 端点 `/mcp`。
- 文档不展开，等 REST 跑通后再说。

## 阶段六：Docker 化（加入现有 docker-compose）

> 目标：把 IBTrade 加进 `KnowHub-AI/docker-compose.yml`，一键起全套。

1. 在 `trade/src/IBTrade.Api/` 加 `Dockerfile`（多阶段 .NET 8）：
```dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY IBTrack.sln .
COPY src/IBTrade.Domain/IBTrade.Domain.csproj src/IBTrade.Domain/
COPY src/IBTrade.Application/IBTrade.Application.csproj src/IBTrade.Application/
COPY src/IBTrade.Infrastructure/IBTrade.Infrastructure.csproj src/IBTrade.Infrastructure/
COPY src/IBTrade.Api/IBTrade.Api.csproj src/IBTrade.Api/
RUN dotnet restore src/IBTrade.Api/IBTrade.Api.csproj
COPY src/ ./src/
RUN dotnet publish src/IBTrade.Api/IBTrade.Api.csproj -c Release -o /app

FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app
COPY --from=build /app .
ENV ASPNETCORE_URLS=http://+:8090
EXPOSE 8090
ENTRYPOINT ["dotnet", "IBTrade.Api.dll"]
```
2. 在 `docker-compose.yml` 加 service：
```yaml
  ibtrade:
    build: ./trade
    container_name: ibtrade
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
      - ConnectionStrings__Default=Host=postgres;Port=5432;Database=ibtrade;Username=postgres;Password=postgres
      - IBKR_FLEX_TOKEN=${IBKR_FLEX_TOKEN}
    ports:
      - "8090:8090"
    depends_on:
      postgres:
        condition: service_healthy
    restart: unless-stopped
```
> 连接串里 `Host=postgres`（容器名），不是 `localhost`——这是新手最常踩的坑。

## 新增一个实体的标准 5 步（背下来）
1. `Domain/Entities` 加实体（继承 `Entity`，用 `required`）
2. `Domain/Repositories` 加接口
3. `Application/xxx` 加 DTO(record) + Service(接口+实现)
4. `Infrastructure/Persistence/Configurations` 加映射 + `Repositories` 加实现 + `DependencyInjection` 注册
5. `Api/Controllers` 加 Controller 委托 Service
然后 `dotnet build` 验证。
